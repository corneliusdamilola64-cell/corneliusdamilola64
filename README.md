# 👋 Why I Approach Data Differently

Before I learned to build dashboards, I learned to question evidence.

My background in **Industrial Chemistry** taught me a principle that continues to shape every analytics project I work on:

> **A conclusion is only as reliable as the process that produced it.**

In science, results aren't accepted because they look convincing—they're accepted because they've been questioned, tested, and validated.

That same mindset defines how I approach data.

Before I create a dashboard, I understand the business problem.

Before I calculate KPIs, I validate the data.

Before I present insights, I ask whether the conclusions can withstand scrutiny.

I believe dashboards don't create value.

**Better decisions do.**
