# Why I Approach Data Differently

Before I learned Power BI, I learned science.

My background in **Industrial Chemistry** taught me something that continues to shape every dashboard I build:

> **A conclusion is only as reliable as the process that produced it.**

In a laboratory, results aren't accepted because they look convincing.

They're accepted because they've been questioned, tested, and validated.

I bring that same mindset into analytics.

Before I build dashboards...

I understand the business problem.

Before I calculate KPIs...

I validate the data.

Before I present insights...

I ask whether the numbers would still hold up if every assumption were challenged.

That evidence-first mindset has guided every project in this portfolio.

Because dashboards don't create value.

**Better decisions do.**
